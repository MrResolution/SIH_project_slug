# Glossary

| Term | Meaning |
| :--- | :--- |
| **ADB** | Asian Development Bank |
| **bar(g)** | Gauge pressure in bar, relative to the local atmosphere |
| **Bingham plastic** | A fluid that does not flow until its yield stress τ<sub>y</sub> is exceeded, then flows with plastic viscosity μ<sub>p</sub> |
| **BMS** | Battery management system |
| **BoM** | Bill of materials |
| **Buckingham–Reiner** | The equation for laminar Bingham-plastic flow in a pipe |
| **CPHEEO** | Central Public Health and Environmental Engineering Organisation (MoHUA) |
| **Desludging** | Emptying faecal sludge from an on-site containment |
| **DR-n** | Design-review item n ([04 §7](04-engineering-calculations.md#7-design-consistency-review)) |
| **Drift-flux model** | A two-phase flow model used for the air-assist void fraction |
| **ERSU** | Emergency Response Sanitation Unit |
| **Excluder** | NC State's auger-and-screen trash-rejecting intake head (Design K) |
| **FMEA** | Failure Mode and Effects Analysis |
| **FOG** | Fats, oils and grease |
| **FS / FSM** | Faecal sludge / Faecal Sludge Management |
| **FSTP** | Faecal Sludge Treatment Plant |
| **GOBARdhan** | Govt. scheme for bio-methanation of organic and cattle waste |
| **GP** | Gram Panchayat |
| **Herschel–Bulkley** | Yield-stress model τ = τ<sub>y</sub> + Kγ̇ⁿ |
| **HIL** | Hardware-in-the-loop testing |
| **K1 / K2** | Safety relays: machine power / PCP enable |
| **LEL** | Lower Explosive Limit (CH₄ ≈ 5% vol) |
| **LiFePO₄ (LFP)** | Lithium iron phosphate battery chemistry |
| **MoHUA / MoJS / MoSJE** | Ministry of Housing and Urban Affairs / Jal Shakti / Social Justice and Empowerment |
| **NAMASTE** | National Action for Mechanised Sanitation Ecosystem |
| **NPSH** | Net positive suction head |
| **ODF / ODF Plus** | Open Defecation Free / sustained ODF with safe solid and liquid waste management |
| **OSS** | On-site sanitation system (septic tank, pit, etc.) |
| **P&ID** | Piping and instrumentation diagram |
| **PBD** | Position-based dynamics (used for the hose rope) |
| **PCP** | Progressive cavity pump (eccentric screw pump) |
| **PEMSR Act** | Prohibition of Employment as Manual Scavengers and their Rehabilitation Act, 2013 |
| **PRV** | Pressure-reducing valve |
| **Radford recipe** | A standardised artificial trash mix for testing pit-emptying equipment |
| **Ratholing** | Suction drawing a narrow channel through sludge while leaving the cake behind |
| **RPN** | Risk priority number (S × O × D) |
| **SBM(G)** | Swachh Bharat Mission (Grameen) |
| **Seed layer** | ≥ 25 mm of sludge left in the tank to keep the digestion bacteria |
| **SOC** | State of charge |
| **STP** | Sewage Treatment Plant |
| **SUY** | Swachhta Udyami Yojana |
| **Supernatant** | Clarified middle liquid layer in a tank |
| **TRL** | Technology Readiness Level |
| **TS** | Total solids (% by mass) |
| **ULB** | Urban Local Body |
| **VFD** | Variable-frequency drive |
| **VIP latrine** | Ventilated improved pit latrine |
| **Web3D** | Real-time interactive 3D in a browser (WebGL2 / WebGPU) |
| **τ<sub>y</sub>, μ<sub>p</sub>** | Yield stress (Pa), plastic viscosity (Pa·s) |
